AUDIO FIRE NAVBAR PACKAGE

Your new wide Audio Fire logo is saved at assets/music-logo.png.
It is displayed directly with object-fit: contain, with no circular frame and no forced crop.

Usage:
1. Extract this ZIP.
2. Keep index.html and the assets folder together.
3. Open index.html to preview.
4. Update the page links to your actual website pages.

The Admin toggle only shows/hides the Admin link; it is not an access-control system. Protect admin pages with server-side authentication.
